# 天天酷跑 · 美术提示词（层叠剪纸风）

画风参考 SCANLINE 的角色插画：**层叠剪纸 / papercraft**，像多层手工剪纸叠出来的立体浮雕，
有细腻纸纹、层与层之间的柔和投影、少量烫金细节，二次元精致脸、大而有神的眼睛。

跑酷游戏里要用的是**可以抠出来的小人/小动物贴图**，所以和 SCANLINE 的海报不同：
**不要边框、不要场景、透明背景、侧面朝右**。

一共 71 张：角色 40 张（每人「奔跑」+「骑乘」两张）、坐骑 19 张、宠物 12 张。

## 操作步骤（用 ChatGPT 生图时）

1. 新建一个对话，先发【通用风格】+ 第一张的描述。
2. 满意后，**在同一个对话里**继续发：「保持和上一张完全相同的画风、比例和质感，画下一张：」+ 下一张的描述。
   同一类（角色 / 坐骑 / 宠物）尽量在同一个对话里画完，风格才统一。
3. 每张下载后按文件名保存为 PNG（例如 `afei_run.png`），放进：
   `天天酷跑/art-src/` 这个文件夹。
4. 全部（或一部分）放好后告诉 Claude，由 Claude 抠图、压缩、接进游戏并发布。

> 不要在提示词里写任何现有动漫角色、游戏或画师的名字，保持原创。
> 某张不满意可以继续说「重新画，脸更精致 / 颜色更偏蓝 / 身体比例再 Q 一点」。
> 如果生成出来不是透明背景，纯白底也可以，Claude 会帮你抠掉。

## 通用风格

### 角色（每次都带上）
```
请画一张 1:1（1024×1024）的游戏角色贴图。
风格：层叠剪纸艺术（layered paper-cut art / papercraft），像多层手工剪纸叠出的立体浮雕，
有细腻纸张纹理、层间柔和投影和少量烫金细节；颜色明亮饱和。
人物：原创二次元 Q 版角色，约 3 头身，脸部精致可爱，大眼睛带细腻高光，表情自信活泼。
视角：完整全身，正侧面朝向画面右边。
背景：透明背景（如果做不到就用纯白色背景）。不要边框、不要场景、不要地面阴影、不要任何文字或水印。
人物居中，占画面高度约 80%。
```

### 坐骑（每次都带上）
```
请画一张 1:1（1024×1024）的游戏坐骑贴图。
风格：层叠剪纸艺术（layered paper-cut art / papercraft），像多层手工剪纸叠出的立体浮雕，
有细腻纸张纹理、层间柔和投影和少量烫金细节；颜色明亮饱和，造型 Q 版可爱。
视角：完整全身，正侧面朝向画面右边，背上（或上方）没有人，留出可以骑乘的位置。
背景：透明背景（如果做不到就用纯白色背景）。不要边框、不要场景、不要地面、不要任何文字或水印。
坐骑居中，占画面宽度约 85%。
```

### 宠物（每次都带上）
```
请画一张 1:1（1024×1024）的游戏宠物贴图。
风格：层叠剪纸艺术（layered paper-cut art / papercraft），像多层手工剪纸叠出的立体浮雕，
有细腻纸张纹理、层间柔和投影和少量烫金细节；颜色明亮饱和。
造型：圆滚滚的 Q 版小精灵，漂浮在空中，大眼睛，非常可爱。朝向画面右边。
背景：透明背景（如果做不到就用纯白色背景）。不要边框、不要场景、不要任何文字或水印。
宠物居中，占画面约 70%。
```
